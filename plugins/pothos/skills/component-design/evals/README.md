Fixed evaluation for this skill. `evals.json` holds the prompts; `rubric.md` holds how outputs are scored and how two versions are compared. Change the skill, rerun the same prompts, compare the scores; never compare runs made with different prompts.

An eval with a `fixture` runs inside a copy of that project: `fixture.py <id> <dest>` copies it, links the cached toolchain's `node_modules` package by package (`scripts/toolchain.sh`, shared with `verify.sh --minimal`) and prints the prompt with `{project}` replaced by the copy's path. Afterwards `reuse_check.py <fixture> <dest> --components … --hooks …` scores criterion 12 from the eval's `reuse` entry. A fixture keeps no `node_modules`, lockfile or cache of its own.
