Fixed evaluation for this skill. `evals.json` holds the prompts; `rubric.md` holds how outputs are scored and how two versions are compared. Change the skill, rerun the same prompts, compare the scores; never compare runs made with different prompts.

An eval with a `fixture` runs inside a copy of that project: `fixture.py <id> <dest>` copies it, links the cached toolchain's `node_modules` package by package (`scripts/toolchain.sh`, shared with `verify.sh --minimal`) and prints the prompt with `{project}` replaced by the copy's path. Afterwards `reuse_check.py <id> <dest>` scores criterion 12 from the eval's `reuse` entry: the primitives the code the run added renders and the hooks it calls, file by file (new files, and lines added to existing ones; comments, strings and reformats do not count; example consumers under `examples/` or named `*Example.tsx` are left out; the shared folders are `src/ui` and `src/hooks` from the project root unless the eval's `reuse` entry says otherwise; a primitive's own element is not a raw control). The shipped fixture is a floor, not a discriminating test: its `AGENTS.md` and its one feature already point at the primitives. A fixture keeps no `node_modules`, lockfile or cache of its own.
