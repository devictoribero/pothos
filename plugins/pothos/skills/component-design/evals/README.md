Fixed evaluation for this skill. `evals.json` holds the prompts; `rubric.md` holds how outputs are scored and how two versions are compared. Change the skill, rerun the same prompts, compare the scores; never compare runs made with different prompts.

An eval with a `fixture` runs inside a copy of that project: `fixture.py <id> <dest>` copies it, links the cached toolchain's `node_modules` package by package (`scripts/toolchain.sh`, shared with `verify.sh --minimal`) and prints the prompt with `{project}` replaced by the copy's path. Afterwards `reuse_check.py <id> <dest>` scores criterion 12 from the eval's `reuse` entry: the primitives and hooks the task calls for, imported by the code the run added (new files, and lines added to existing ones). The shipped fixture is a floor, not a discriminating test: its `AGENTS.md` and its one feature already point at the primitives. A fixture keeps no `node_modules`, lockfile or cache of its own.
